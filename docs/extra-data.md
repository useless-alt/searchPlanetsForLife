# Режим «Показать дополнительные данные» (задача 18)

Документ описывает сквозную политику видимости служебных данных (п. 11.2,
U12, U36, U37). Источник истины для кода — `apps/web/src/extra/registry.ts`;
этот файл обязан совпадать с реестром по составу идентификаторов, что
проверяет тест `apps/web/src/extra/extra.test.tsx`.

## Зачем режим существует

Раздел 11.2 главнее разделов 4, 9, 10 и 13: по умолчанию экран показывает
только то, что нужно для работы — режим расчёта, параметры модели, выборку
и таблицу. Счётчики выборки, сдвиг ранга, `Q_data`, число источников,
тег «эксп.» и технические подписи — служебные: они раскрываются
переключателем «Показать дополнительные данные» в шапке, справа от
«Обновить данные».

Режим влияет **только на видимость**. Расчёты, индексы, фильтры и
ранжирование остаются полными; при переключении данные не перезагружаются
и не пересчитываются, выбранная планета и сортировка сохраняются.
Единственное исключение — сортировка по скрываемой колонке `Q_data`:
при выключении режима она сбрасывается на `rank asc` (10.5.6, U12).

Состояние переключателя хранится в `sessionStorage['exo.showExtraData']`
и восстанавливается при обновлении страницы в рамках сессии. Ошибки
доступа к хранилищу не ломают приложение: значение остаётся в памяти.

## Как добавить новый скрываемый элемент

1. Добавьте запись в `EXTRA_REGISTRY` (`apps/web/src/extra/registry.ts`):
   уникальный `id`, место (`where`) и описание со ссылкой на пункт ТЗ.
2. Добавьте строку с тем же `id` в таблицу «Что скрыто» этого документа.
3. Оберните элемент в `ExtraOnly`:

   ```tsx
   <ExtraOnly id="table.qdata" store={store}>
     <TableCell>…</TableCell>
   </ExtraOnly>
   ```

   `ExtraOnly` при выключенном режиме не рендерит детей вовсе — элемент
   не попадает ни в DOM, ни в порядок табуляции, ни в доступное дерево.
   При включённом режиме корневой элемент получает `data-extra="<id>"`.
4. Если элемент виден ещё и по другой причине (как Δ при включённом
   сравнении с упрощённым ESI), вне режима рендерьте его без `ExtraOnly`,
   а внутри режима — через `ExtraOnly`.
5. Запустите тесты: проверка уникальности идентификаторов и совпадения
   реестра с этим документом входит в `extra.test.tsx`.

Никакой другой способ скрывать служебные данные (`display: none`,
`hidden`, условный рендер в обход реестра) в коде не используется.
