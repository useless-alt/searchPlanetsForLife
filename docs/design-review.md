# Дизайн-ревизия (задача 27a)

Проверка космической темы по скриншотам: 11 состояний × 3 размера.
Кадры снимает `npm run design:shots` (Playwright + Chromium/SwiftShader),
складывает в `docs/screens/` (каталог в `.gitignore`).

Состояния: A1 загрузка, A2 таблица, A3 карточка, A4 «Параметры модели»,
A5 «Фильтры», A6 «Источники» (degraded), A7 меню «Ещё» (методика),
A8 подсказка, A9 сцена — цель «Планета», A10 сцена — цель «Звезда»,
A11 заглушка планеты.

Уровни: **P1** — наложение, обрезка, нечитаемость, контраст; **P2** —
выбивается из темы, слабая иерархия, лишний шум; **P3** — полировка.

## Итог

- Открытых P1 и P2 **в области 27a** нет: все исправлены в этой задаче.
- Два пункта вне области: окно «Методика» (17a) и камера/масштаб сцены
  системы (22/25, проверка — на полноэкранном холсте 27c). Они записаны
  сюда, чтобы не потерялись, и не считаются замечаниями темы.
- Размер 390 px снят по требованию задачи, но мобильной раскладки нет по
  решению проекта; кадр показывает прокручиваемое полотно, а не дефект.

## Воспроизводимость

`npm run pretest:shots` собирает `e2e/fixtures/catalog.json` из
`buildDatasetRecords()` через `mergeCatalog`; `npm run design:shots`
поднимает Vite, ставит `installMockApi` и снимает кадры через CDP.
Сеть не используется, шрифты и иконки лежат в бандле.
